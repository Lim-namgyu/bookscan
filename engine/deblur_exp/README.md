# 흐린 글자 복원 모델 (실험)

합성 글자 사진(Noto CJK 한국어·영어 글꼴 렌더링 + 흐림·잡음·JPEG 열화)으로 학습한 아주 작은 CNN
(9,585 파라미터, 3x3 conv 6층, 잔차 출력). `deblur_v2.onnx` 입력 `img` 1×1×H×W float(0~1), 출력 같은 크기.

- `gen_data.py` 데이터 생성, `train.py` 학습(PyTorch 없으면 numpy 로 같은 모델을 학습), `eval.py` 실제 사진 평가
- `REPORT.md` 결과: 흐린 양면 사진에서 획이 또렷해지지만, 어둡고 거친 종이에서 작은 점을 만들어 냄
- `../deblur.py` 로 엔진에서 불러 쓸 수 있게 해 두었으나 **아직 기본 파이프라인에는 넣지 않음**
  (고전 방식의 획 되살리기(restore_strokes)가 비슷한 효과를 더 안전하게 냄). 실제 폰 사진에서 효과가
  확인되면 선명도 지도(local_sharpness)로 흐린 곳에만 섞어 넣을 계획
